# RoadMapForge

## 🚀 Overview

**RoadMapForge** is an interactive learning roadmap platform designed to help users navigate different learning paths. It provides curated roadmaps, progress tracking, and community contributions. Future plans include AI-generated learning paths based on user progress.

## 🌟 Features

- **Interactive Roadmap UI** with nodes and progress tracking
- **Structured JSON-based roadmap data** for dynamic rendering
- **User Authentication** (OAuth/Firebase)
- **User Contributions & Voting** for roadmap improvements
- **AI-powered Learning Path Recommendations** (using OpenAI API)
- **Smooth Animations & UX Enhancements**

## 🛠️ Tech Stack

- **Frontend**: React.js, TailwindCSS, React Flow/D3.js
- **State Management**: Zustand/Redux
- **Backend (Future Expansion)**: Node.js, Express, MongoDB/Firebase
- **AI Integration (Future Expansion)**: OpenAI API for personalized learning paths

## 🔧 Installation & Setup

1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/RoadMapForge.git
   cd RoadMapForge/frontend
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.
